사이트 개설 전

  • 사이트 개설 중→사이트 개설 중

구독 상태 (구독 상태별 정의와 같은 순서)

  • 미신청→기존 사이트 관리 화면지금처럼 이용 · Pro 신청은 원할 때만
  • 무료 제공 중→어드민 홈Basic은 어드민 홈 (Basic), Pro는 어드민 홈 (Pro)
  • 무료 제공 종료→

    무료 제공 기간이 종료되어 사이트가 중지되었습니다.
    결제를 진행하시면 바로 다시 이용하실 수 있습니다.

    확인[확인]을 누르면 구독 관리 (무료 제공 종료)로 이동합니다.
  • 이용 중→어드민 홈Basic은 어드민 홈 (Basic), Pro는 어드민 홈 (Pro)
  • 유예→어드민 홈Basic은 어드민 홈 (Basic), Pro는 어드민 홈 (Pro)
  • 미납→

    결제가 확인되지 않아 관리자 화면이 읽기 전용으로 바뀌었습니다.
    미납 결제를 완료하시면 바로 정상 이용하실 수 있습니다.

    확인[확인]을 누르면 구독 관리 (미납)로 이동합니다.
  • 해지 예약→어드민 홈이용 종료일까지 이용 중과 같이 처리
  • 만료→

    서비스 이용 기간이 만료되어 사이트가 중지되었습니다.
    보관 기간(90일) 안에 다시 결제하시면 사이트가 그대로 복구됩니다.

    확인[확인]을 누르면 구독 관리 (만료)로 이동합니다.

부계정 결제 권한 없음 3

구독 상태 (구독 상태별 정의와 같은 순서)

  • 미신청→기존 사이트 관리 화면권한이 있는 메뉴만 보임
  • 무료 제공 중→어드민 홈권한이 있는 메뉴만 보임
  • 무료 제공 종료→

    현재 사이트의 서비스 이용이 일시 중지되어 로그인하실 수 없습니다.
    서비스를 다시 이용하시려면 사이트 소유자에게 결제를 요청해 주시기 바랍니다.

    확인[확인]을 누르면 로그인 화면에 그대로 머뭅니다.
  • 이용 중→어드민 홈권한이 있는 메뉴만 보임
  • 유예→어드민 홈권한이 있는 메뉴만 보임
  • 미납→어드민 홈 (읽기 전용)권한이 있는 메뉴만 조회
  • 해지 예약→어드민 홈권한이 있는 메뉴만 보임
  • 만료→

    현재 사이트의 서비스 이용이 일시 중지되어 로그인하실 수 없습니다.
    서비스를 다시 이용하시려면 사이트 소유자에게 결제를 요청해 주시기 바랍니다.

    확인[확인]을 누르면 로그인 화면에 그대로 머뭅니다.

화면 설명

FLEXG 홈페이지에서 [로그인]을 눌렀을 때의 로그인 화면과, 로그인 후 이동 흐름을 한 화면에 정리했습니다.

1 로그인 화면은 지금 화면을 그대로 씁니다. [회원가입하기]는 회원가입 화면으로 이동합니다.
2 대표계정은 구독 상태에 따라 이동할 화면이 다릅니다. 구독 상태는 구독 상태별 정의의 8가지와 같은 이름 · 순서로 보여주고, 사이트 개설 전 단계는 따로 묶습니다. 오른쪽 파란 칸을 누르면 해당 화면으로 갑니다. 무료 제공 종료 · 미납 · 만료는 알럿으로 이유를 먼저 알린 뒤 [확인]을 누르면 구독 관리로 이동합니다.
3 부계정은 결제 권한이 없습니다. 같은 8가지 상태 순서로 보여주며, 미납이면 어드민을 조회만 할 수 있고, 사이트가 중지된 상태(무료 제공 종료 · 만료)면 어드민에 들어갈 수 없어 로그인 화면에서 알럿만 보여줍니다.
