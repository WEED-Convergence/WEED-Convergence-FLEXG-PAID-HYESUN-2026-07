1 현재 플랜과 상태, 다음 결제일을 보여줍니다. [구독 관리]는 구독 관리 화면으로 이동합니다.
2 CDN 기본량(Basic 50GB / Pro 100GB)과 사용량을 보여줍니다. 기본량은 CDN 화면과 기준이 달라 확정 전까지 TBD로 표시했습니다.
3 사이트 개설 완료와 배포 상태를 따로 보여줍니다(PLT-01).
4 Basic은 Page Builder 제작(F02)으로 바로 연결하고, FLEXG Page 사용 여부는 묻지 않습니다. F02 화면은 아직 없어 동작하지 않습니다.
5 개설 직후 할 일을 체크리스트로 보여줍니다. Basic은 Page Builder 제작, 회원 기능 설정, 홈페이지 배포 체크리스트 순서이며, 항목을 누르면 해당 화면으로 이동합니다.
