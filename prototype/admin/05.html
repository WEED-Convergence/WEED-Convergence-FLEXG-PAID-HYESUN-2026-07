  2. 2가입 · 인증 · 약관
  3. 3역할 · 알림
  4. 4동작 검수

1

사이트에 회원 기능이 필요하신가요? 2

방문자가 가입·로그인해야 하는 기능(회원 전용 게시판, 주문 내역 등)이 있다면 필요합니다.

3

화면 설명

어드민 홈의 시작 체크리스트에서 [회원 기능 설정]을 눌렀을 때 표시됩니다.

1 회원 기능 설정은 회원 필요 여부 → 가입·인증·약관 → 역할·알림 → 동작 검수 4단계로 진행합니다.
2 첫 단계에서 회원이 필요한지 묻습니다. [필요 없어요]를 고르면 나머지 단계를 모두 생략하고 체크리스트에서 완료로 처리합니다.
3 [다음]은 가입·인증·약관 단계로 넘어갑니다.
