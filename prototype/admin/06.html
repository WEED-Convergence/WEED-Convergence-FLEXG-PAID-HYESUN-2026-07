  • 배포에 실패해도 초안과 기존 배포본은 그대로 보존되며, 다시 시도할 수 있습니다.

화면 설명

Basic 고객이 어드민 홈의 [배포 체크리스트]를 눌렀을 때 표시됩니다. 예시는 6단계 검수 중인 상태입니다.

1 기본정보 → 템플릿 → 콘텐츠 → 문의 → 주소/SSL → 검수 → 배포 → 접속 확인 8단계로 진행합니다.
2 검수에서 PC·모바일·메뉴·링크·폼·SSL을 확인합니다. 포틀릿·커머스 바인딩·판매 기능은 Basic에서 쓸 수 없어야 하며, 화면뿐 아니라 API·URL·배포 결과까지 확인합니다.
3 추가 트래픽이나 고도화 CRM 없이 첫 배포가 가능합니다. 자료가 부족하면 초안으로 저장하고 필요한 자료만 안내합니다. Pro 전용 기능을 요청하면 대체 구성이나 Pro 상향을 안내합니다. 배포에 실패하면 초안과 기존 배포본을 보존한 뒤 다시 시도합니다.
4 [초안 저장]은 작성 내용을 초안으로 저장하고, [검수 완료하고 배포]는 배포를 진행합니다.
