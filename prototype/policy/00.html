빌링정책서

구독 결제(빌링)가 어떻게 동작하는지 한눈에 정리한 문서입니다. 결제는 모두 토스페이먼츠를 통해 처리합니다.

1. 결제 기본

항목정책관련 화면
플랜Basic(홈페이지) · Pro(쇼핑몰 판매) 2가지 월 구독만 제공한다. 플랜은 페이지 수가 아니라 사이트 용도와 상품 판매 여부로 나눈다. Free 플랜과 연 결제는 제공하지 않는다.플랜 선택
계약 단위사이트 단위로 계약한다. 계정 1개 = 사이트 1개이며, 결제수단과 청구서도 사이트 단위다. 이미 사이트가 있는 계정은 사이트를 새로 살 수 없다.—
결제 대행사모든 결제는 토스페이먼츠로 처리한다. 쇼핑몰 판매용 PG와 FLEXG 구독 결제용 PG는 별도 계약이다.—
결제 방식등록 카드의 빌링키(정기결제용 카드 등록 키)로 매월 자동 결제한다. 카드번호는 우리 서버에 저장하지 않는다. 결제 성공 여부는 PG 거래 내역으로 확인한다.—
결제 시각결제일 오후 2시에 한 번 결제한다. 이번 이용 기간 플랜 요금과 추가 트래픽 요금(선불), 직전 이용 기간 사용료(후불)를 함께 결제한다.이용 중
결제 권한결제 · 플랜 상향 · 추가 트래픽 구매 · 해지 · 카드 변경은 사이트 소유자(사이트당 1명, 사이트를 가입한 계정)만 할 수 있다. 다른 역할은 사이트 소유자에게 직접 요청한다. 제작을 맡긴 사람이나 초대받은 제작자에게는 결제 · 해지 권한을 주지 않는다.결제 권한 없음
이용 중 (결제 권한 없음)
결제 권한 없음 (팝업)
결과 미확인결제 결과를 확인하지 못한 건은 실패로 처리하며, 다시 결제하지 않는다(중복 결제 방지).결제 확인 중

2. 결제수단 (카드)

항목정책관련 화면
등록 개수카드는 사이트당 1장만 등록할 수 있다.카드 있음
미등록
적용 범위등록한 카드는 그 사이트의 플랜 요금, 추가 트래픽 요금, 사용료(트래픽 초과 · 문자 · 알림톡 등) 결제에 함께 쓴다.카드 있음
등록·변경카드를 등록하거나 바꾸면 토스페이먼츠에서 카드 인증을 거친다. 인증이 끝나면 완료 또는 실패 화면으로 자동 이동한다.처리 중
완료
등록 실패카드사 인증에 실패하면 카드는 바뀌지 않고 기존 카드가 그대로 유지된다.실패
카드 삭제이용 중(무료 제공 중 · 이용 중 · 유예 · 미납 · 해지 예약)에는 카드를 삭제할 수 없고, 다른 카드로 교체만 할 수 있다. 그만두려면 구독 관리에서 해지한다. 구독이 만료된 뒤에는 삭제할 수 있다.카드 삭제 불가
미납 중 카드 변경결제가 밀린 상태에서 카드를 바꾸면, 별도 버튼 없이 밀린 결제를 자동으로 다시 시도한다. 성공하면 정상 이용으로 돌아가고, 실패하면 유예(또는 미납)가 계속된다.완료 · 미납 결제 완료

3. 무료 제공

항목정책관련 화면
기간 · 횟수카드 미등록 14일, 카드 등록 시 한 달. 계정당 1회다. 가입 때 카드 등록은 선택이며, 빌링키 발급에 성공해야 유효한 카드로 본다.결제 전 확인 · 정기결제 동의
무료 제공 중
고객 표기무료 표현은 "14일 무료 제공(카드 등록 시 첫 달 무료)"으로 통일한다. "Free 플랜" · "무료 플랜" · "평생 무료" 표현은 쓰지 않는다. 엔드유저 화면(홈페이지 · 쇼핑몰)에는 무료 제공 기간 관련 표시를 하지 않는다.플랜 선택
카드 등록 고객무료 제공이 끝난 다음 날 오후 2시에 같은 플랜으로 자동 첫 결제한다. 첫 결제에 실패하면 유예 없이 사이트를 중지한다.무료 제공 중
결제 확인 중
무료 제공 종료 · 결제 실패
카드 미등록 고객14일째 23:59에 종료되고 사이트를 중지한다. 결제하면 바로 다시 열리며, 결제한 날이 결제일이 된다.무료 제공 종료 · 결제 실패
종료 후 미결제사이트는 즉시 중지되고, 관리자는 결제와 진행 중인 주문 처리만 할 수 있다. 데이터는 90일 보관하고, 지나면 완전 삭제한다.무료 제공 종료 · 결제 실패
요금무료 제공 기간에는 별도 요금이 없다. 트래픽은 과금하지 않고 첫 결제일부터 집계한다. 문자 · 알림톡 등 이용료는 과금한다.무료 제공 중
이용 범위무료 제공 기간에도 제작과 배포를 할 수 있다. Pro는 판매용 PG 승인 후 주문 · 결제와 주문 처리를 할 수 있다(승인 전에는 무통장입금을 포함해 판매할 수 없다). 무료 제공 기간 중 Basic → Pro 변경이 가능하며, 남은 기간은 Pro로 이용한다.결제 전 확인 · 정기결제 동의

4. 플랜 가격 · 정기결제

항목정책관련 화면
플랜 가격정상가 Basic 12,900원 / Pro 23,900원, 오픈 특가 Basic 9,900원 / Pro 17,900원 (월, 부가세 별도). Pro 요금은 Pro 단독 요금이며 Basic 요금에 더하는 방식이 아니다. 기본 제공 트래픽은 Basic 50GB / Pro 100GB이고 플랜 요금에 포함된다.플랜 선택
오픈 특가2/18~4/30 가입 고객에게 첫 결제부터 연속 12개월 적용하고, 13개월째부터 정상가로 바뀐다. 무료 제공 기간은 12개월에 넣지 않고, 미납 등으로 결제되지 않은 달도 12개월에 포함한다(연장 없음). 고객 화면에는 "12개월"로 표기한다. 할인은 플랜 요금에만 적용한다. 해지 후 다시 가입하면 오픈 특가를 다시 적용하지 않는다.이용 중
금액 표기결제 화면과 청구서에는 "정상가 + 오픈 특가 할인" 항목으로 적는다(예: 플랜 요금 12,900원 / 오픈 특가 할인 -3,000원). 할인이 있으면 할인 아래에 "할인 적용 금액 (부가세 별도)"을 보여주고 그 10%를 부가세로 적는다. 할인이 없으면 "플랜 요금 → 부가세 → 결제 금액" 3줄로 적는다(예: Pro 23,900원 + 부가세 2,390원 = 26,290원).결제 가능
부가세표시 가격은 부가세 별도다. 실제 결제할 때 부가세 10%를 더한다. (예: 17,900원 + 1,790원 = 19,690원)결제 가능
이용 기간 · 결제일이용 기간은 결제일부터 다음 결제일 전날까지다. 매월 결제일 오후 2시에 자동 결제한다. 다음 결제 금액은 사용료가 확정되기 전이라 "(예상 · 사용량 별도)"로 표기한다.이용 중
결제 확인 중결제 결과를 아직 모를 때는 다시 결제할 수 없다. 이미 결제됐을 수 있기 때문이다.결제 확인 중
처리 중 (지연)
중복 결제 방지같은 계약으로 처리 중인 결제가 있으면 새 결제를 만들지 않는다. 버튼을 여러 번 누르거나 새로고침해도 한 번만 결제된다.진행 중인 결제 있음
재청구 금지이미 결제가 끝난 계약은 다시 청구하지 않는다.이미 완료된 결제
갱신 지연결제는 됐는데 이용 기간 반영이 늦어지면 시스템이 자동으로 다시 처리한다. 이때 다시 청구하지 않는다.결제 완료 · 갱신 지연
결제 후 진행결제 완료 후에도 권한 적용, 사이트 배포, 판매 시작은 각각 따로 진행한다. 결제는 됐는데 사이트 복구 · 권한 적용이 실패하면 추가 결제 없이 같은 계약으로 자동 복구한다.결제 확인 · 사이트 복구 중
복구 대기

5. 결제 실패 · 유예 · 미납 · 만료

항목정책관련 화면
실패 사유카드 오류, 한도 초과, 인증 실패, PG 오류, 결제 취소 5가지로 나눠 안내한다. 실패하면 청구되는 금액은 없다.결제 실패 · 취소
유예정기결제에 실패하면 7일 유예(정상 이용)가 된다. 유예 기간 동안 매일 오후 2시에 자동 재시도하고, 재시도가 실패할 때마다 사이트 소유자에게 결제 요청 알림을 보낸다.유예
미납 · 유예
한 번에 결제플랜 요금과 사용료는 한 번에 결제하며, 실패하면 둘 다 같은 절차(재시도 · 유예 · 만료)를 따른다.청구 상세 (미납)
유예 중 해결카드를 바꾸면 밀린 결제가 자동으로 다시 진행되고, 같은 카드로 [다시 결제]할 수도 있다. 성공하면 정상 이용으로 돌아간다.완료 · 미납 결제 완료
재결제 (팝업)
미납 (읽기 전용)7일차 재시도까지 실패하면 즉시 관리자 화면을 읽기 전용으로 바꾼다. 읽기 전용에서도 결제수단 변경과 재결제는 할 수 있고, 재배포는 할 수 없다. 사이트(엔드유저 화면)는 만료 전까지 정상 운영한다.미납 · 읽기 전용 (유예 종료)
만료첫 결제 실패 후 30일에 만료한다. 만료되면 사이트를 중지하고, 관리자 화면은 재결제만 할 수 있다. 만료 후 90일 이내에 재결제하면 그대로 복구한다(미납분 + 새 한 달 요금 결제). 90일이 지나면 완전 삭제한다.만료
기존 고객 미납신규 플랜 선택 전 기존 고객은 현행 미납 처리(관리자 접속 제한)를 그대로 적용한다.—
