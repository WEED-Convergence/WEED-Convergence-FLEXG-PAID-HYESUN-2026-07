빌링정책서

구독 결제(빌링)가 어떻게 동작하는지 한눈에 정리한 문서입니다. 결제는 모두 토스페이먼츠를 통해 처리합니다.

1. 결제 기본

항목정책관련 화면
결제 대행사모든 결제는 토스페이먼츠로 처리한다.—
결제 방식토스페이먼츠 자동결제(빌링)를 쓴다. 카드를 한 번 등록하면 매달 자동으로 결제된다.—
카드 정보 보관카드번호는 우리 서버에 저장하지 않는다. 토스페이먼츠가 발급한 빌링키로만 결제한다.—
결제 권한결제 권한이 있는 계정(소유자)만 카드 등록·변경·삭제, 결제, 플랜 변경, 해지를 할 수 있다. 권한이 없으면 조회만 할 수 있다.결제 권한 없음
이용 중 (결제 권한 없음)
결제 권한 없음 (팝업)
기존 고객기존 고객은 Basic/Pro 플랜 결제가 생기지 않는다. 기존 서비스 이용료는 "서비스 이용료 정기결제" 메뉴에서 확인한다.미신청

2. 결제수단 (카드)

항목정책관련 화면
등록 개수카드는 계정당 1개만 등록할 수 있다.카드 있음
미등록
적용 범위계정당 사이트는 1개만 연결할 수 있다. 등록한 카드는 그 사이트의 구독료와 사용량 추가 요금(트래픽 초과 · 추가 용량) 결제에 함께 쓴다.카드 있음
등록·변경카드를 등록하거나 바꾸면 토스페이먼츠에서 카드 인증을 거친다. 인증이 끝나면 완료 또는 실패 화면으로 자동 이동한다.처리 중
완료
등록 실패카드사 인증에 실패하면 카드는 바뀌지 않고 기존 카드가 그대로 유지된다.실패
카드 삭제구독 중(체험 중 · 이용 중 · 유예 · 해지 예약)에는 카드를 삭제할 수 없다. 카드는 변경만 할 수 있고, 그만두려면 구독 관리에서 해지한다. 구독이 만료된 뒤에는 삭제할 수 있다.카드 삭제 불가
미납 중 카드 변경결제가 밀린 상태에서 카드를 바꾸면, 별도 버튼 없이 밀린 결제를 자동으로 다시 시도한다. 성공하면 유예가 풀리고, 실패하면 유예가 계속된다.완료 · 미납 결제 완료
완료 · 미납 결제 실패

4. 정기결제

항목정책관련 화면
결제 주기한 달에 한 번, 이용 기간이 끝나는 다음 날 자동으로 결제된다.이용 중
오픈 특가2/18~4/30에 가입한 고객(체험으로 시작한 고객은 체험 시작일 기준)은 첫 결제일부터 연속 12개월 동안 오픈 특가를 적용하고, 13개월째부터 정상가로 바뀐다. 체험 기간은 12개월에 넣지 않고, 미납 · 유예 · 만료로 결제되지 않은 달도 12개월에 포함한다(연장 없음). 기존 고객도 2/18~4/30에 신규 플랜을 고르면 12개월 적용한다. Basic 오픈 특가 9,900원 → 정상가 12,900원, Pro 오픈 특가 17,900원 → 정상가 23,900원 (부가세 별도). 고객 화면에는 "12개월"로 표기한다. (POL-01, BIL-09)이용 중
오픈 특가 표기결제 화면과 청구서에는 "정상가 + 오픈 특가 할인" 항목으로 적는다(예: 플랜 요금 12,900원 / 오픈 특가 할인 -3,000원). 오픈 특가 할인은 플랜 요금에만 적용하고, 추가 트래픽 · 초과 요금 · 서비스 이용료는 정상 요금이다. Pro 가격에 Basic 요금을 따로 더하지 않는다. 할인이 있으면 할인 아래에 "할인 적용 금액 (부가세 별도)"을 보여주고 그 10%를 부가세로 적는다. 할인이 없으면 할인 · 할인 적용 금액 줄 없이 "월 구독료 → 부가세 → 결제 금액" 3줄로 적는다(예: Pro 23,900원 + 부가세 2,390원 = 26,290원). (BIL-01, BIL-09)결제 가능
부가세표시 가격은 부가세 별도다. 실제 결제할 때 부가세 10%를 더한다. (예: 17,900원 + 1,790원 = 19,690원)결제 가능
사용량 추가 요금월 구독료 외에 사용량에 따라 추가 요금이 생길 수 있다. 그래서 화면의 다음 결제 금액은 사용량이 확정되기 전의 예상 금액이다.이용 중
결제 확인 중결제 결과를 아직 모를 때는 다시 결제할 수 없다. 이미 결제됐을 수 있기 때문이다.결제 확인 중
처리 중 (지연)
중복 결제 방지같은 계약으로 처리 중인 결제가 있으면 새 결제를 만들지 않는다. 버튼을 여러 번 누르거나 새로고침해도 한 번만 결제된다.진행 중인 결제 있음
재청구 금지이미 결제가 끝난 계약은 다시 청구하지 않는다.이미 완료된 결제
갱신 지연결제는 됐는데 이용 기간 반영이 늦어지면 시스템이 자동으로 다시 처리한다. 이때 다시 청구하지 않는다.결제 완료 · 갱신 지연
결제 후 개설 실패결제는 됐는데 사이트 개설이 실패하면, 추가 결제 없이 같은 계약으로 자동 복구한다.결제 확인 · 사이트 개설 중

6. 플랜 변경 · 해지 · 만료

항목정책관련 화면
플랜 변경Basic에서 Pro로만 바꿀 수 있다. Pro에서 Basic으로는 바꿀 수 없다. 오픈 특가 적용 중에 올리면 Pro 오픈 특가(17,900원)로 이어서 남은 기간 동안 적용하고, 차액도 오픈 특가 기준(17,900원 - 9,900원)으로 남은 일수만큼 일할 계산한다. 변경 적용 시점은 아직 정하지 않았다. TBD변경

8. 결제 후 개설 · 권한 · 트래픽 적용

항목정책관련 화면
계약 반영 시점서버에서 결제 성공을 확인한 뒤에 계약을 반영하고 사이트 개설을 시작한다. (PAY-02)결제 확인 · 사이트 개설 중
