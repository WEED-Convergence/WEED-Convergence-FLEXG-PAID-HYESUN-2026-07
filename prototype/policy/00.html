빌링정책서

구독 결제(빌링)가 어떻게 동작하는지 한눈에 정리한 문서입니다. 결제는 모두 토스페이먼츠를 통해 처리합니다.

1. 결제 기본

항목정책관련 화면
결제 대행사모든 결제는 토스페이먼츠로 처리한다.—
결제 방식토스페이먼츠 자동결제(빌링)를 쓴다. 카드를 한 번 등록하면 매달 자동으로 결제된다.—
카드 정보 보관카드번호는 우리 서버에 저장하지 않는다. 토스페이먼츠가 발급한 빌링키로만 결제한다.—
결제 권한결제 권한이 있는 계정(소유자)만 카드 등록·변경·삭제, 결제, 플랜 변경, 해지를 할 수 있다. 권한이 없으면 조회만 할 수 있다.결제 권한 없음
이용 중 (결제 권한 없음)
결제 권한 없음 (팝업)
기존 고객기존 고객은 Basic/Pro 플랜 결제가 생기지 않는다. 기존 서비스 이용료는 "서비스 이용료 정기결제" 메뉴에서 확인한다.미신청

2. 결제수단 (카드)

항목정책관련 화면
등록 개수카드는 계정당 1개만 등록할 수 있다.카드 있음
미등록
적용 범위등록한 카드는 계정의 모든 사이트에 똑같이 적용된다. 사이트마다 다른 카드를 쓸 수 없다.카드 있음
등록·변경카드를 등록하거나 바꾸면 토스페이먼츠에서 카드 인증을 거친다. 인증이 끝나면 완료 또는 실패 화면으로 자동 이동한다.처리 중
완료
등록 실패카드사 인증에 실패하면 카드는 바뀌지 않고 기존 카드가 그대로 유지된다.실패
카드 삭제유료 플랜을 쓰는 중에 카드를 삭제하면 해지가 예약된다. 이용 종료일까지는 계속 쓸 수 있다.카드 삭제
미등록 · 해지 예약
해지 예약 (카드 삭제)
해지 예약 자동 취소카드 삭제로 해지가 예약된 상태에서 새 카드를 등록하면 해지 예약이 자동으로 취소된다.카드 등록 완료 · 해지 예약 취소
미납 중 카드 변경결제가 밀린 상태에서 카드를 바꾸면, 바꾼 뒤 바로 밀린 결제를 다시 시도하도록 안내한다.완료 (미납 재시도 연결)

3. 무료 체험

항목정책관련 화면
체험 횟수체험은 계정당 처음 1번만 할 수 있다.체험 중
체험 기간체험 기간은 14일이다.체험 중
자동 유료 전환체험이 끝나면 체험하던 플랜 그대로 자동 결제된다.체험 중
결제 확인 중
전환 결제 실패체험이 끝나고 결제에 실패하면 이용이 멈춘다. 카드를 바꾸거나 다시 결제하면 바로 다시 쓸 수 있고, 쇼핑몰 데이터는 그대로 보관된다.체험 종료 · 결제 실패

4. 정기결제

항목정책관련 화면
결제 주기한 달에 한 번, 이용 기간이 끝나는 다음 날 자동으로 결제된다.이용 중
사용량 추가 요금월 구독료 외에 사용량에 따라 추가 요금이 생길 수 있다. 그래서 화면의 다음 결제 금액은 사용량이 확정되기 전의 예상 금액이다.이용 중
결제 확인 중결제 결과를 아직 모를 때는 다시 결제할 수 없다. 이미 결제됐을 수 있기 때문이다.결제 확인 중
처리 중 (지연)
중복 결제 방지같은 계약으로 처리 중인 결제가 있으면 새 결제를 만들지 않는다. 버튼을 여러 번 누르거나 새로고침해도 한 번만 결제된다.진행 중인 거래
재청구 금지이미 결제가 끝난 계약은 다시 청구하지 않는다.이미 완료된 결제
결제 완료
갱신 지연결제는 됐는데 이용 기간 반영이 늦어지면 시스템이 자동으로 다시 처리한다. 이때 다시 청구하지 않는다.결제 완료 · 갱신 지연
결제 후 개설 실패결제는 됐는데 사이트 개설이 실패하면, 추가 결제 없이 개설만 다시 시도한다.결제 확인됨 · 사이트 개설 중
개설 실패 복구

5. 결제 실패와 유예

항목정책관련 화면
실패 사유카드 오류, 한도 초과, 인증 실패, PG 오류, 결제 취소 5가지로 나눠 안내한다. 실패하면 청구되는 금액은 없다.결제 실패 · 취소
유예정기결제에 실패하면 바로 멈추지 않고 유예 상태가 된다. 유예 종료일까지는 계속 쓸 수 있다.유예
미납 · 유예
유예 기간유예 기간은 7일이다.유예
유예 중 해결유예 종료일 전에 카드를 바꾸고 결제를 다시 시도하면 정상 이용으로 돌아간다.유예
완료 (미납 재시도 연결)
유예 종료유예 종료일까지 결제가 안 되면 이용이 중단될 수 있다.유예

6. 플랜 변경 · 해지 · 만료

항목정책관련 화면
플랜 변경바꾼 플랜은 다음 결제일부터 적용된다. 그 전까지는 지금 플랜을 그대로 쓴다.변경
해지 예약해지는 바로 되지 않고 예약된다. 이용 종료일까지는 계속 쓸 수 있고, 다음 결제는 일어나지 않는다.해지 예약 확인
해지 예약
해지 예약 취소이용 종료일 전이라면 해지 예약을 언제든 취소할 수 있다.해지 예약
만료이용 종료일이 지나면 만료된다. 다시 쓰려면 플랜을 새로 신청해야 한다.만료
