회원가입 정책서

회원가입부터 플랜 선택, 체험 시작, 사이트 개설까지의 규칙을 정리한 문서입니다. 결제 규칙은 빌링정책서, 개설 이후 구독 상태는 구독관리 정책서를 따릅니다.

1. 가입 기본

항목정책관련 화면
가입 대상새로 사이트를 만들려는 고객이 가입한다. 초대받은 제작자는 FLEXG Page 로그인 경로로 들어오므로 이 흐름을 거치지 않는다.—
계정과 사이트계정당 사이트는 1개만 연결할 수 있다.—
입력 항목담당자 본인인증, 아이디(.flexg.shop), 비밀번호, 비밀번호 확인, 담당자 이메일을 모두 입력해야 한다. 담당자 본인인증을 가장 먼저 받는다.회원가입
가입 약관필수 3개(플렉스지 이용약관, 개인정보 수집 및 이용, 연동 업체 회원가입)와 선택 1개(광고성 정보 수신)를 받는다. [약관 전체 동의]를 체크하면 모두 체크된다. 필수에 모두 동의해야 가입할 수 있다.회원가입
중복 가입담당자 인증을 마쳤을 때 같은 담당자로 가입된 계정이 있으면 이미 가입된 회원임을 알린다. 아이디는 일부만 보여주고 [로그인]과 [아이디 · 비밀번호 찾기]로 안내하며, 새 계정은 만들지 않는다.이미 가입된 회원 (팝업)
FLEXG Page 워크스페이스가입하면 FLEXG Page 워크스페이스를 자동으로 만들고 연동한다. Basic, Pro, 체험 모두 같다. 연동에 실패해도 가입·개설·결제는 그대로 두고 연동만 다시 시도한다.— (10/14 결정)

2. 가입 후 분기

항목정책관련 화면
기존 고객가입 후 보유 사이트·계약이 확인되면 기존 고객(EXT)으로 안내한다. 새 사이트 구매 흐름(플랜 선택·템플릿·개설)으로 보내지 않고 구독 관리로 연결한다. 기존 고객은 Basic/Pro 플랜 결제가 생기지 않는다.가입 완료 · 기존 고객 (EXT)
미신청
기존 고객 판정무엇으로 보유 사이트·계약을 찾는지(담당자 본인인증 정보 등), 판정 시점(담당자 인증 단계 또는 가입 완료 후), 새 계정을 기존 사이트의 소유자로 바로 연결할지는 아직 정하지 않았다. TBD가입 완료 · 기존 고객 (EXT)
신규 고객보유 사이트·계약이 없으면 바로 플랜 선택으로 이동한다. 별도의 가입 완료 화면 없이 플랜 선택 맨 위에 가입 완료 인사를 보여준다.플랜 선택
플랜 미신청 신규 계정가입 후 플랜을 신청하지 않고 나간 신규 계정(사이트 없음)은 다시 로그인하면 플랜 선택으로 이동한다. 이때는 가입 완료 인사를 보여주지 않는다. 체험이나 결제를 시작하기 전까지 사이트를 만들지 않는다.플랜 선택
진행 중인 신청플랜 선택이나 결제 전 확인에 들어갈 때 같은 계정에 유료 계약·진행 중인 결제·개설 요청이 있으면 새 신청을 만들지 않고 진행 중인 신청을 안내한다.진행 중인 신청 있음

3. 플랜 · 템플릿 선택

항목정책관련 화면
플랜 추천운영 목적과 상품·주문·회원 데이터 사용 여부로만 추천한다. 회사·브랜드 소개 홈페이지이면서 데이터를 쓰지 않으면 Basic, 그 외는 Pro다. 페이지 수나 사이트 이름·아이디로는 추천하지 않는다. 추천은 선택이며, 다른 플랜을 골라도 된다.플랜 선택
홈페이지에서 고른 플랜홈페이지 요금 페이지에서 플랜을 고르고 가입하면 그 플랜을 미리 선택하고 추천 문항은 접어 둔다.플랜 선택
노출하지 않는 것Free 플랜과 연 할인 경로는 보여주지 않는다.—
추가 트래픽기본으로 선택해 두지 않는다. 사지 않아도 첫 배포를 할 수 있다.플랜 선택
FLEXG PageBasic은 FLEXG Page가 포함(필수)이다. Pro는 사용 여부를 고를 수 있고, 결제 후 어드민 홈에서 한 번만 고른다. 추가 요금은 없다.플랜 선택
템플릿Pro는 쇼핑몰 템플릿, Basic은 판매 기능이 없는 홈페이지 템플릿을 업종별로 고른다. [미리보기]로 템플릿을 모바일 화면 크기로 확인하고 바로 적용할 수 있다. 템플릿을 고르기 전에 [플랜 다시 선택]으로 플랜을 바꿀 수 있다.템플릿 선택 (Pro)

4. 체험 시작 · 결제 전 확인

항목정책관련 화면
무료 체험Basic, Pro 모두 14일 무료 체험으로 시작한다. 체험은 계정당 1번이며, 체험 중 결제 금액은 0원이다.결제 전 확인 · 정기결제 동의
카드 등록체험을 시작할 때도 정기결제 카드를 반드시 등록해야 한다.결제 전 확인 · 정기결제 동의
자동 결제 안내체험 종료 후 자동 결제일과 금액을 미리 보여준다. 정상가를 먼저 쓰고, 출시가 할인과 부가세를 따로 적는다.결제 전 확인 · 정기결제 동의
결제 약관필수 5개(유료 서비스 이용약관, 정기결제 이용약관, 전자금융거래 이용약관, 개인정보 제3자 제공(토스페이먼츠), 체험 종료 후 자동 결제 동의)에 모두 동의하고 카드를 등록해야 시작 버튼이 켜진다. 약관 본문은 팝업에서 본다.결제 전 확인 · 정기결제 동의
약관 보기 (팝업)
Pro 체험 제한Pro는 체험 중 배포와 실제 판매(PG 결제)를 할 수 없음을 체험 시작 전에 안내한다. Basic에는 이 안내를 보여주지 않는다.결제 전 확인 · 정기결제 동의
체험을 이미 쓴 계정체험 표시 없이 같은 화면에서 바로 결제한다. 버튼은 [n원 결제하기]이고, 결제일부터 매월 같은 날 결제된다.결제 전 확인 · 정기결제 동의

5. 사이트 개설

항목정책관련 화면
개설 순서서버에서 신청(또는 결제)을 확인한 뒤 계약 반영 → 사이트 개설 → 플랜 권한 적용 → 기본 트래픽 적용 순서로 진행한다.사이트 개설 중
중복 신청 방지창을 닫거나 새로고침해도 신청·결제가 중복되지 않는다.사이트 개설 중
개설 실패신청(또는 결제)은 그대로 두고 같은 계약으로 자동 복구한다. 다시 신청·결제하거나 사이트를 새로 만들지 않는다. 복구 후 어드민 홈에 복구 안내를 처음 한 번만 보여준다.개설 복구 대기
개설 완료모든 단계가 끝나면 사이트 개설 완료 화면으로 자동 이동한다. 개설된 사이트 주소와 플랜·체험 정보를 보여주고, 아직 공개(배포) 전임을 안내한 뒤 [어드민으로 이동]으로 어드민 홈에 들어간다. 개설 완료와 배포 상태는 따로 보여준다.사이트 개설 완료
